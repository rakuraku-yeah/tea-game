# 一葉茶屋 · 一葉から、ひと椀へ。

直接用瀏覽器開啟 `index.html`，不需安裝套件或建置。使用簡單 SVG 插畫，包含三種無名客人外觀、37 種需求、日本綠茶與台灣茶共九種成品。原有存檔會保留。

## 畫面與操作

- 上方是客人；中間是單排成品茶櫃檯；下方是製茶桌。
- 開始時桌上是空茶盤。點中央茶盤，會開啟原料選單。
- 選好原料後，把中央茶葉拖到亮起的道具即可加工。滑鼠、觸控與觸控筆均使用 Pointer Events；也可以直接點道具，或用 Tab / Enter 操作。
- 不符合工序的道具變灰停用。拖到灰色道具會說明原因，不會加工；拖到空白處或取消拖曳也不會改變這一批。
- 點茶盤或「換葉」可重新選原料；選下原料即開始新的一批。選單會說明尚未完成的加工會重置，已入庫的茶與圖鑑保留。
- 完成乾燥後鑑定入庫。選擇櫃檯上的茶，再按「端給客人」。同一批不能重複領取。
- 庫存超過可見範圍時，使用櫃檯左右箭頭或橫向捲動；櫃檯不會擴展成多排。
- 圖鑑在獨立頁面內捲動，不擠壓製茶桌。

桌面以視窗高度配置；已檢查 1280×720 與手機 390×844 可完整顯示主要操作。更矮的畫面會保留最小可用高度，可稍微捲動，避免把操作按鈕壓得過小。

## 客人與經營

客人隨機出現，外觀與需求獨立抽選，不會連續出現同一種外觀。同一輪 37 題不重複，其中 5 題接受兩種茶。客人入場約 0.9 秒後才顯示需求；「聊聊口味」只補充感官線索，不給配方。

預設日文，可用右上方選單切換繁體中文；語言選擇會保存，不會重置遊戲。

開店前不限時備茶，點「準備好了，開店」後門簾打開，才開始接客與三分鐘營業倒數。查看圖鑑、選原料、閱讀對話或切換到背景時暫停倒數，也可手動暫停。時間結束會顯示當日收入、成本與收支；點「開始下一天」回到備茶，庫存與未完成批次保留。符合需求才扣一份茶並收到茶錢；不合需求時保留庫存並提示。

初始資金 180 茶錢（舊版存檔升級時補一次）。原料：日照嫩葉 6、成熟葉 4、遮陰嫩葉 12、台灣茶菁 8。加工：萎凋、攪拌各 1；蒸製、揉捻、乾燥、炒菁、氧化各 2；焙煎、團揉各 3。無效加工不收費。數值集中於 `app.js` 的 `economy`，是遊戲平衡值，不是現實茶價。未入庫的批次換料會放棄已花成本。資金低於 18 且沒有庫存時，可在備茶／結算畫面領取補助至 40，補助不算銷售收入。第五天打烊後會結算累計收支、接待人數與圖鑑進度；玩家可繼續自由經營，或保留圖鑑與庫存並開始新的五日週期。

已入庫的當前煎茶／番茶／清香烏龍若繼續焙煎，先扣回原本那份，鑑定後變成焙茶／焙香烏龍。當前批次出售後，原料與工序清空，下批需重新購料。庫存是獨立成品，不會因換原料而消失。

## 探索路線

### 日本綠茶

- 日照嫩葉 → 蒸製 → 揉捻 → 乾燥：煎茶
- 成熟茶葉 → 蒸製 → 揉捻 → 乾燥：番茶
- 遮陰嫩葉 → 蒸製 → 揉捻 → 乾燥：玉露
- 遮陰嫩葉 → 蒸製 → 乾燥（不揉捻）：碾茶
- 煎茶或番茶 → 焙煎：ほうじ茶

### 台灣茶

- 台灣茶菁 → 萎凋 → 攪拌靜置 × 1 → 炒菁 → 揉捻 → 乾燥：包種茶
- 台灣茶菁 → 萎凋 → 攪拌靜置 × 2 → 炒菁 → 揉捻 → 團揉整形 → 乾燥：清香烏龍
- 清香烏龍 → 焙煎：焙香烏龍
- 台灣茶菁 → 萎凋 → 揉捻 → 充分氧化 → 乾燥：台灣紅茶

這是教學簡化，不是實際生產配方。攪拌次數代表遊戲中的香氣階段，現實需依葉況判斷；團揉按鈕合併初乾與反覆包揉、解塊。紅茶先揉捻再補足氧化，以乾燥的熱停止酵素反應；烏龍則先炒菁停止氧化再揉捻。不能靠烘焙就推定為凍頂、鐵觀音，也不能把所有紅茶當紅玉。

知識來源：

- [茶及飲料作物改良場：台灣特色茶分類與加工製程](https://www.tbrs.gov.tw/ws.php?id=4748)
- [茶及飲料作物改良場：包種茶](https://www.tbrs.gov.tw/ws.php?id=3781)
- [茶及飲料作物改良場：紅茶](https://www.tbrs.gov.tw/ws.php?id=3788)
- [伊藤園：日本茶種類](https://www.itoen-global.com/allabout_greentea/type/)

## 素材替換

目前只使用 `assets/simple/` 的 SVG，保留舊素材但不在遊戲載入精緻 PNG。

- `customer-haru.svg`、`customer-gaku.svg`、`customer-sumie.svg`：三張獨立人物圖。檔名沿用舊版，遊戲不顯示名字；`object-fit: contain` 保持比例。
- `shop.svg`：茶屋場景。
- `tea-empty.svg`：空茶盤。
- `tea-*.svg`：四種原料、加工階段與九種成品。`app.js` 的 `spriteStyle()` 控制檔名。
- `tools/steam.svg`、`roll.svg`、`dry.svg`、`roast.svg`：日本綠茶道具。
- `tools/wither.svg`、`shake.svg`、`kill.svg`、`oxidize.svg`、`ball.svg`：新增台灣茶道具。

以同名 SVG 覆蓋即可替換。茶葉建議保留 `viewBox="0 0 240 240"`，人物為 `0 0 240 300`，道具為 `0 0 120 110`。

## 程式與存檔

- `index.html`：分區標示的遊戲畫面與兩個 overlay 選單。
- `style.css`：有註解分區的桌面、手機、拖曳與圖鑑樣式。
- `app.js`：茶葉資料、製程規則、37 題需求、存檔、渲染與 Pointer Events。所有加工統一經過 `processAction()` 與 `reason()` 驗證。
- `workshop.js`：同桌蒸籠、揉台、乾燥狀態與桌面拖曳。
- `i18n.js`：日文文案、37 組客人對話與可逆的畫面翻譯。
- `tests/game.test.cjs`：不依賴套件的規則、庫存與存檔測試。

程式碼使用兩格縮排與換行，已用 Prettier 整理。

沿用 `one-leaf-save-v1` 保存圖鑑，`one-leaf-shop-v2` 保存庫存、茶錢與接待人數。新開頁面會重新抽來客。新增 `one-leaf-business-v3` 一併保存資金、庫存、日數、剩餘時間、收支與已付費的未完成批次；關閉頁面期間不扣時間。不同網址或瀏覽器不共用存檔；停用 localStorage 時可遊玩，但不保存。

## 2026-10-19 核對與後續設計

## 同桌加工與五日營業

所有加工直接在同一張桌面，不再開啟加工 overlay。選料、圖鑑、委託與對話仍使用原本選單。

- 蒸製：拖茶葉入蒸籠，等約 2.5 秒，點蒸籠開蓋；散熱約半秒後直接拖到下一件器具。
- 揉製：將蒸好的葉子直接拖到揉台，左右交替搓揉三下，自動完成。可用左右鍵或點揉台代替。
- 乾燥：從揉台拖到乾燥區，點一下攤開，等約半秒即完成，接著可以鑑定。
- 茶葉始終留在目前的器具上；中央茶盤不重複顯示同一批茶。其他工序也會保留茶葉所在位置，原本的製程限制照常生效。
- 加工完成才扣費，收回尚未完成的茶不收該道加工費。過去已付的原料與工序費用不退。
- 操作時間是遊戲縮短示意，不是真實製茶時間。桌面加工時營業繼續計時；手動暫停、圖鑑與選單仍會暫停。
- 舊 overlay 的未完成工序會轉成桌面狀態，不重複收費。新的桌面工序及所在器具會存檔。
- 每輪營業為五天；每天開店前不限時製茶，開店後有三分鐘接待客人。
- 第五天打烊時顯示營業收入、製茶支出、最終收益、接待人數、圖鑑收集與現有茶錢。舊版三段委託與指定茶會已暫時移除。

`workshop.js` 管理桌面工序與委託，`style.css` 的 `.desk-*` 為器具上的葉子、蒸籠蓋與手揉動畫。原本簡單素材均保留。
